# rabanian.ir

The personal site of Amin Rabanian — an AI educator and software product manager — selling courses to a Farsi-speaking audience and hosting the free tools and gated resources that go with them.

## Language

### People & brand

**Learner** (دانش‌پذیر):
A person who has enrolled in a Course.
_Avoid_: student (دانشجو), user, customer

**Rabanian Academy** (آکادمی ربانیان):
The publishing brand under which Courses and Tools are released; the site's author.

**Support** (پشتیبانی):
The Telegram account a visitor messages for questions and enrollment.
_Avoid_: contact, help

### Offering

**Course** (دوره):
A paid training product with a title, a category, a description and a price in million toman.
_Avoid_: class, program, product

**Masterclass** (مسترکلاس):
The flagship Course — the AI programming and web-design masterclass. Enrolling in it unlocks every Locked Tool. It is the only Course shown with a banner.
_Avoid_: featured course, main course (the "flagship" badge is a label on it, not its name)

**Brand** (برند):
A company Amin has worked with or advised, shown by name only.
_Avoid_: client, partner, logo

**Testimonial** (نظر):
A quote from a Learner, attributed by name and role.
_Avoid_: review, feedback

**Experience** (سابقه):
One entry in the résumé: a role, an employer, a date range and a one-line summary. Education entries are a separate list, not Experiences.
_Avoid_: job, position

### Toolbox

**Toolbox** (جعبه‌ابزار):
The section of the site listing all Tools.

**Tool** (ابزار):
A resource offered to visitors; either Free or Locked.

**Free Tool** (ابزار آزاد):
A Tool anyone can open without enrolling.

**Locked Tool** (ابزار ویژه):
A Tool reserved for Masterclass Learners. On the site it is shown but cannot be opened.
_Avoid_: premium, disabled, coming soon

**HTML Editor** (ویرایشگر HTML):
The one Free Tool: a page where a visitor writes HTML, CSS and JS and sees the result live. Its Farsi name is the design's; the English term matches it.
_Avoid_: playground, sandbox, code editor (that is the Code Pane)

**Code Pane**:
The text-editing area inside the HTML Editor where one of the three files is typed. One Code Pane is visible at a time, chosen by tab.
_Avoid_: editor (ambiguous with HTML Editor)

**Preview** (پیش‌نمایش):
The sandboxed frame inside the HTML Editor that renders the visitor's three files as a page. It is Farsi and right-to-left by default.
_Avoid_: output, result

**Starter Template** (قالب شروع):
The three files the HTML Editor opens with and resets to; a short Farsi page with explanatory comments.
_Avoid_: boilerplate, default code

### Layout

**Rail** (ردیف):
A horizontally scrolling, snap-aligned row of cards (Courses, Brands, Testimonials), used instead of a grid on narrow screens.
_Avoid_: carousel, slider, swiper
